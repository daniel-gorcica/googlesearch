# Citace a Zdroje

## AI Nástroje a Prompty

Při tvorbě tohoto projektu jsem využil AI asistenta **Claude (Anthropic)** pro generování kódu a vysvětlení postupů. Zde jsou hlavní použité prompty:

1. **Základní struktura a vyhledávání:**
   - *Prompt:* "Vytvoř HTML strukturu pro hlavní vyhledávací stránku (index.html) ve stylu Googlu. Formulář musí mířit na akci `https://www.google.com/search` s metodou GET a parametrem `q`."
   - *Prompt:* "Přidej k formuláři tlačítko pro 'I'm Feeling Lucky' s parametrem `btnI=1`."

2. **Obrázky a Pokročilé vyhledávání:**
   - *Prompt:* "Vytvoř stránku `images.html`, která bude mít stejný formulář, ale s přidaným skrytým inputem `tbm=isch` pro vyhledávání obrázků."
   - *Prompt:* "Vytvoř stránku `advanced.html` s formulářem pro pokročilé vyhledávání. Použij parametry `as_q`, `as_epq`, `as_oq`, `as_nq`."
   - *Prompt:* "Přidej na všechny stránky odkazy v pravém horním rohu pro navigaci mezi Hledáním, Obrázky a Pokročilým vyhledáváním."

3. **Design (Retro/Cyberpunk styl):**
   - *Prompt:* "Uprav CSS tak, aby web vypadal jako retro hra. Použij font `Press Start 2P` pro nadpisy, tmavé pozadí s jemnou mřížkou, neonové barvy (růžová a zlatá) a přidej glow efekty na tlačítka."
   - *Prompt:* "Vytvoř animované pixelové logo Google pomocí HTML spanů a CSS text-shadow."

4. **Formulářová stránka:**
   - *Prompt:* "Vytvoř stránku `forms.html`, která bude obsahovat co nejvíce HTML formulářových prvků (text, email, password, number, date, color, range, select, textarea, checkbox, radio, tlačítka). Nemusí být funkční, jde pouze o ukázku. Přizpůsob ji retro designu projektu."

## Obrázky a ikony
- **Favicon:** Vytvořen vlastnoručně jako SVG (pixelové G).
- **Ikona lupy:** Stažena z volně dostupného SVG zdroje (Material Icons).
